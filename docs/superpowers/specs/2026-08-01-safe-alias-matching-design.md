# 安全别名匹配设计

## 目标

让 K8s、Loki 和 DB MCP 接受常见环境/别名表达，同时避免自动路由到错误集群、日志环境或数据源。

## 规则

1. 保留精确匹配，并作为最高优先级。
2. 规范化匹配忽略 Unicode 全半角差异、大小写、空白和常见分隔符。
3. 模糊匹配会移除“环境、集群、一期、二期、UAT、生产”等通用词；仅在剩余业务名称能够唯一包含于一个已注册别名时返回该别名。
4. 无候选或多候选均抛出配置错误；多候选不自动选择。
5. 错误消息不暴露 kubeconfig、账号、密码、token 或连接串。

## 示例

- `二期道路环境` 唯一匹配 `道路(道路、筑路、养护)(二期UAT)`，允许调用。
- `重型` 同时可能匹配多个环境时，拒绝并要求提供正式名称。
- `不存在环境` 不匹配任何已注册别名，拒绝。

## 范围

- K8s：解析 `cluster` 到服务端预注册集群。
- Loki：解析 `environment` 到 `env.yaml` 中的环境。
- DB：解析只读数据源 `alias`。
- 不改变任何访问权限、查询能力或凭据存储方式。
